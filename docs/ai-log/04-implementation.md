## 中身を説明できるようにしておくところ

- 決定の更新と履歴の追加を1つのトランザクションで書く理由(片方だけ残ると履歴が嘘になる)
- AIの返事を「説明文 → 区切り行 → JSON」にして、説明文だけを画面に流すしくみ(`jobs.py` の `Splitter`)
- 区切り行が2つの断片にまたがって届いても取りこぼさない工夫
- 選択肢を1つ選んだときはAIを呼ばず、2つ以上なら矛盾チェックのためにAIを呼ぶ分け方
